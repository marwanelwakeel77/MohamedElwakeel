الوكيل – النسخة المتصلة بـ Supabase
====================================
ارفع ملفات هذا المجلد إلى نفس GitHub repository واستبدل الملفات القديمة.

تم تضمين Project URL وPublishable key اللذين أرسلهما المستخدم داخل index.html.
المفتاح Publishable مناسب للمتصفح؛ لا تضع أبداً Secret/service_role key في الموقع.

قبل الاستخدام:
1. تأكد أن SQL السابق تم تشغيله بنجاح في Supabase.
2. ارفع index.html وmanifest.webmanifest وsw.js إلى جذر GitHub repository، مع استبدال النسخ القديمة.
3. انتظر اكتمال GitHub Pages ثم افتح الموقع.
4. أنشئ حساباً واحداً فقط لصاحب الشركة باستخدام بريده وكلمة مرور قوية.
5. إذا كان تأكيد البريد مفعلاً، افتح رسالة Supabase وأكد البريد ثم سجل الدخول.
6. جرّب إضافة تاجر تجريبي، ثم أضف مبلغاً وخصم جزءاً منه، وتأكد من سجل الحركات.
7. لا تدخل بيانات فعلية قبل إكمال الاختبار.

ملاحظات:
- البيانات تُخزن في Supabase وتظهر بعد تسجيل الدخول من أجهزة مختلفة.
- التطبيق لا يتيح إنشاء حسابات موظفين أو تعديل/حذف الحركات.
- لا تشارك كلمة المرور أو أي Secret key.
- النسخة الاحتياطية الحالية تنزل ملف JSON على الجهاز.
- الخطط المجانية لها حدود وقد تتوقف المشاريع غير النشطة مؤقتاً؛ احتفظ بنسخة احتياطية دورية.
